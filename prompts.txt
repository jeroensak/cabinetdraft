Prompt 3 — Cabinet geometry and spaces

Implement pure domain geometry for carcass panels, shelves and spaces.

Required formulas:

Given:

W = outside width
H = outside height
D = outside depth
T = corpus thickness
B = back thickness

When the back is enabled:

carcassDepth = D - B

otherwise:

carcassDepth = D

Internal width:

internalWidth = W - 2T

Physical basic panels:

side:
H × carcassDepth × T

top:
internalWidth × carcassDepth × T

bottom:
internalWidth × carcassDepth × T

back:
H × W × B

Shelf:

internalWidth × carcassDepth × T

Implement a canonical physical-panel representation suitable for later reuse by:

SVG/domain geometry;

Cut List.

Do not put screen coordinates into this representation.

Implement:

deriveSpaces(module, settings)

Spaces must be calculated from:

top/bottom panels;

sorted shelves.

Spaces are derived only.

Each space should expose at minimum:

bottom boundary
top boundary
bottom coordinate
top coordinate
free height

Test at least:

empty module;

one shelf;

multiple shelves;

unsorted persisted shelf array;

default 800 × 2200 × 600 example.

For:

800 × 2200 × 600
T = 18
B = 3

test exactly:

side:       2200 × 597
top/bottom: 764 × 597

Do not implement front geometry yet.

Stop after this slice.

Prompt 4 — Front geometry

Implement canonical front geometry in the pure TypeScript domain.

This geometry must later be consumed by both:

SVG rendering;

Cut List.

Do not calculate these measurements in React.

Implement semantic:

DoorFront
DrawerFront

with stable boundary references.

Implement helpers to resolve a boundary to a physical vertical coordinate.

Rules:

Horizontal

Single full-width front:

width = W - 2G

Double door:

leafWidth = (W - 3G) / 2

If leaf width is non-integer millimetres, expose this as an invalid geometry condition rather than rounding.

Vertical outer boundaries

Module bottom:

G

Module top:

H - G

Internal shelf boundaries

centre = shelf.bottom + T / 2

For a front below that shelf:

top = centre - G / 2

For a front above that shelf:

bottom = centre + G / 2

Internal shelves inside one door's covered range do not influence that door's geometry.

Implement:

deriveFrontGeometry(...)

or equivalent canonical functions.

Required exact test:

module: 800 × 2200
frontGap: 2
double full-height door

must derive two physical leaves:

397 × 2196 × frontThickness

Also test:

partial door between shelves;

drawer front;

adjacent fronts sharing a shelf;

door spanning several spaces;

fractional double-door width.
